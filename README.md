# Facility Job Log

PWA for technicians to record **Attend** / **Work Done** with photos against facility tickets.

- Technician app: `index.html`
- Admin (upload Excel, view records, download Excel): `admin.html`
- Backend (Google Apps Script → Google Sheet + Drive): `backend/Code.gs`
- Setup guide: [SETUP.md](SETUP.md)

Paste your Apps Script Web app URL into `config.js` (`API_URL`) to go live. Empty = demo mode.
